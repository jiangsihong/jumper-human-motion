# 视频动作提取说明

最新大幅度映射见 [第二版说明](../v2/README.zh.md)。本目录保留第一版；上一级预览入口可以选择第一版或第二版。

本文记录最初的视频片段提取。现已完成的人体关键点、机器人映射、参考轨迹和预览见 [映射说明](MAPPING.zh.md)。尚未启动强化学习训练。

原视频位于上两级的 `video` 目录，保持原样。原视频约 35.39 秒，分辨率 1026×720，30 帧/秒。

## 三个动作片段

以下时间对应原视频，起点包含、终点不包含。保留了动作前后的少量站立衔接，已排除人物介绍镜头和片尾。

| 文件 | 原视频时间 | 片段时长 | 帧数 |
| --- | --- | --- | --- |
| `clips/01_side_step.mp4`：闪身步 | 2.800～9.300 秒 | 6.500 秒 | 195 |
| `clips/02_kick_step.mp4`：踢腿与交叉步 | 12.400～16.500 秒 | 4.100 秒 | 123 |
| `clips/03_arm_body_sway.mp4`：张臂摆身 | 24.900～32.300 秒 | 7.400 秒 | 222 |

第三段在原视频约 28.37～30.30 秒切换到了近景，部分腿脚不可见，主片段保留这些动作镜头。
另外提供 `clips/full_body/03_arm_body_sway_full_body.mp4`：原视频 24.900～28.333 秒，时长约 3.433 秒、103 帧，全程为近景切换前的全身画面。它只是第三个动作的局部短片，不是完整表演，也没有验证为循环动作。

## 文件用途和检查结果

- `clips/`：三个主要动作视频；`clips/full_body/`：第三个动作额外的全身短版。
- `previews/`：每个视频的 12 帧预览拼图。
- `manifest.json`：精确的裁剪帧号、时长、分辨率、校验值与处理说明。
- `extract_clips.py`：可重复执行的提取脚本。

输出保持原分辨率和 30 帧/秒，使用 H.264 编码，未裁切画面、镜像、变速、插帧或去水印。动作片段已静音，原音频仍在原视频中。每个输出均完整解码，并核对了帧数、帧率和尺寸；同时核对原视频未被修改。

动作时间由人工查看画面选定。这里描述的视频片段本身不能直接作为关节轨迹交给 PPO 训练；后续映射生成的数据和人体识别结果另见映射说明。

## 重新提取

在现有的 `pytorch` 环境中执行：

```sh
python video/human_motion_01/v1/extract_clips.py
```

脚本会覆盖重建同名片段、拼图和清单，不修改原视频，不启动训练。
