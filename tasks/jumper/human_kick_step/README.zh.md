# 浪子踢球：独立模仿训练任务

训练素材是第二版 02_kick_step 的实际物理参考记录，文件校验值与原文件一致，没有缩小动作。两条前肢对应人的双臂，其余四条腿对应改编的脚步，使用 PPO 学习跟随参考动作。

## 启动训练

```sh
conda activate pytorch
cd jumper-human-motion
python scripts/train.py --task jumper.human_kick_step --backend warp --device cuda:0 --num_envs 256 --max-iterations 2000 --headless
```

三个任务依次训练。2000 轮是初始预算，不保证学会，也不是耗时估计。打开终端打印的 TensorBoard 网址即可查看曲线。请从工程根目录启动，日志会在 `logs/jumper/jumper.human_kick_step/时间戳/`。

## 训练后查看最新策略

```sh
python scripts/play.py --task jumper.human_kick_step --backend warp --device cuda:0 --num_envs 1 --measure --steps 456 --stop-on-done
```

这是策略实时控制电机的物理仿真，不是播放映射姿态。只评估从第一帧开始的一次尝试，在片尾自动跳回前结束；任务自身也加入了片尾终止。要检查腿部幅度、抬脚、跟踪误差和完整完成情况。训练随机抽取四秒片段，完成一个片段不等于完成整段。

要继续停止的训练，在训练命令加 `--resume`，此时轮数表示再训练多少轮。不要加载旧行走任务权重，因为观察输入不同。

## 数据检查与限制

原来的四足共面检查不适用于这些抬脚参考。本任务提供逐帧近地足标签：每帧至少两个足点位于站姿足点高度上下 5 毫米内，所有足点不得比站姿足点高度低超过 3.5 毫米。标签内容、采样间隔和阈值进入转换缓存校验；旧任务继续保留原检查，关节限位、连续性和模型一致性检查也保留。近地标签是几何代理，不是接触力或稳定性证明。

右后腿保留了约 163 毫米的相对机身前后行程、61 毫米上下行程，并有单独的右后腿跟踪奖励，避免在全身平均中忽略踢腿。

策略读取仿真位置误差和线速度；真机需要相应状态估计和控制器支持。当前不是可直接部署的真机任务。没有操作员速度指令，因此无需 `controls.yaml`。

## 启动验证结果

RTX 5060 Laptop GPU（8 GiB）、warp:cuda、256 环境的五轮检查已完成，总奖励 0.18 → 0.15。这只说明入口能运行，不代表学会。检查权重、回放和测量见 `startup_validation.json`；没有留下正式长训练。

共享加载器、注册和任务分类共 51 项检查通过、1 项跳过；独立只读复核未发现启动阻断。原来的闪身步、舞蹈任务、视频和已有权重保留。

五轮检查策略在开启观察噪声的回放中，于第 186 步提前结束，未完成要求的 456 步（仿真 3.72 秒），保存了 185 行测量。它还没有学会动作，检查权重不应当作训练结果。
